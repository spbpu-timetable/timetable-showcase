# Сайт-визитка проекта Timetable

Одностраничный сайт с описанием проекта автоматического составления расписания для университета:
какую задачу он решает, как собирались требования, как устроено решение и какие результаты получены
на реальных данных факультета.

Статическая страница без сборки и зависимостей: `index.html`, `styles.css` и скриншоты в `assets/`.

## Локальный просмотр

```bash
python -m http.server 8899
```

Затем открыть http://127.0.0.1:8899

## Публикация

Сайт публикуется через GitHub Pages из ветки `main`, папка `/` (root).
